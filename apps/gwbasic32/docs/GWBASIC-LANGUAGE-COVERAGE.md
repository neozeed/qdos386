# GW-BASIC on QDOS/386 — Statement and Function Coverage

This matrix is the observed behaviour of the current Win32 build (`build/gwbasic.exe`, Wine 9.0)
for each statement and function, typed once after `NEW`. It was generated by
`tests/coverage/probe_matrix.py` and rendered by `tests/coverage/matrix_to_md.py`; regenerate
both after any change to `src/`. The QDOS build runs the same interpreter code, and every
statement with a test case is also run on QDOS (see `docs/GWBASIC-RUNTIME-REPORT.md`).

## Classes

- **runs**: the statement or function executes and reports no error for the probe. The output
  column shows what it printed. Several "runs" entries are no-ops (for example `END`, `CLS`,
  `TRON`), and a `runs` result is not evidence that the behaviour matches the original.
- **not implemented (Advanced Feature)**: the statement is tokenized and its stub reports
  `Advanced Feature`. Example: `PSET`, `OPEN`, `LOC`.
- **Illegal function call (argument refused)**: the statement or function refuses the argument form
  used by the probe (for example `INP(1)`, `COLOR 7`, `RENUM`).
- **Syntax error (keyword not tokenized)**: the keyword is not in the token table for this build.
  See `docs/GWBASIC-KNOWN-LIMITATIONS.md`, section 3.

The reference (original Microsoft GW-BASIC) was not available in this environment. The matrix
records the port's behaviour, not a comparison with the original.

## Tested beyond the probe

The probe checks a single form per item. The following are tested in `tests/cases` (Win32 and QDOS
unless noted) and are the basis for the coverage claims in the runtime report:

- Program control: `for_loop`, `for_gosub`, `nested_for`, `long_loops` (FOR to 200000, nested
  100 × 1000, 20000 GOSUB calls), `gosub_return`, `return_nogosub`, `next_nofor`, `whl_*`
  (WHILE/WEND, including the FNDWND skip cases), `stored_run`, `stored_two_lines`, `list_program`,
  `new_clears`, `fre_clear`, `syntax_error`.
- Data: `read_data` (READ/DATA/RESTORE and Out of DATA), `dim_array`, `dim_more`, `vars_num_str`.
- Numerics: `arith_mixed`, `int_ops`, `int_single`, `int_edge`, `dp_ops`, `dp_var_print`,
  `div_zero`, `div_zero_run`, `print_arith`, `def_fn`.
- Strings: `string_concat`, `string_funcs`, `string_slice`, `string_gc`, `string_array_gc`,
  `print_string`.
- Files and system: `save_load`, `save_ascii`, `save_ascii_big`, `save_dirfull`,
  `save_diskfull_empty`, `save_diskfull_partial`, `load_errors`, `load_errors_83`, `merge_ascii`,
  `merge_errors`, `files_pattern`, `system_exit`, `llist_unsupported`.
- Known failing or skipped on QDOS: `save_write_error` (kernel finding), `save_readonly` (harness
  cannot attach read-only media). See the handback.
