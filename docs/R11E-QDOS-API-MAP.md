# R11E QDOS API map

Status: R11E. Source: the C68 libc 4.24.5 `qdos/` reference (historical 68000 names,
prototypes and documented behaviour), mapped onto the native QDOS/386 kernel traps.
Generated inventory: `docs/R11E-C68-XREF.csv` (102 symbols), produced by
`scripts/r11e-c68-xref.py` from the C68 sources. The mapping table is explicit in that
script; nothing is inferred from names.

## Classification

| R11E status | Meaning | Count |
|---|---|---|
| semantic | Same purpose and arguments; QDOS/386 service behaves the same for supported cases | 1 |
| approximate | Same purpose with a documented difference (no timeout, one heap, return value differs, read only, and similar) | 13 |
| native-only | A QDOS/386 wrapper exists but the C68 convention (pointer pairs, common/user heaps) is not provided | 2 |
| unsupported | No QDOS/386 service. The name is not exported as a working function; see the C89 coverage table for its status (`blocked` or `missing`) | 86 |

The 102 C68 names by group: multitasking/heap 48, channel I/O 18, screen/graphics 13,
file system 11, window/utility 9, date 2, other 1.

## Mapped services

| C68 group | Native QDOS/386 wrapper | Trap | R11E status | Notes |
|---|---|---|---|---|

| channel byte I/O | `qd_read`, `qd_getc`, `qd_putc`, `qd_write` | 0x1A, 0x17, 0x16 | approximate | One byte per call through `qd_getc`; no timeout argument |
| channel seek | `qd_seek` | 0x1B | approximate | Absolute positions only; seeking beyond end of file is refused |
| jobs: activate | `qd_job_activate` | 0x0A | approximate | No timeout; returns 0, or -1 if already active |
| jobs: priority | `qd_job_chprio`, `qd_job_info` | 0x0B, 0x0C | approximate | `mt_prior` returns 0, not the old value; read it with `qd_job_info` first |

## Unsupported services

The 86 unsupported names are reported as they are, not stubbed. They fall in these families:

- Date and calendar: `cn_date`, `cn_day`, `fs_date`. The trap ABI has no RTC service.
- File system (writes, metadata, versions): `fs_headr`, `fs_heads`, `fs_load`, `fs_mdinf`, `fs_mkdir`, `fs_posre`, `fs_save`, `fs_vers`. The FAT16 volume is read only and there are no directories below the root.
- I/O management: `io_delete`, `io_rename`, `io_format`, `io_edlin`, `io_fline`, `io_fstrg`, `io_sstrg`, `io_qeof`, `io_qin`, `io_qout`, `io_qset`, `io_qtest`, `io_serq`, and `ioa_sown`, `iow_xtop`. Writes and queue services do not exist for WIN1_.
- Multitasking extras: `mt_alres`, `mt_baud`, `mt_cjob`, `mt_dmode`, `mt_free`, `mt_frjob`, `mt_inf`, `mt_ipcom`, `mt_jinf`, `mt_ldd`, `mt_liod`, `mt_lnkfr`, `mt_lpoll`, `mt_lschd`, `mt_lxint`, `mt_rdd`, `mt_riod`, `mt_rjob`, `mt_rpoll`, `mt_rschd`, `mt_rxint`, `mt_shrink`, `mt_trans`, `mt_trapv`. Their QDOS services (inter-job communication, serial lines, interrupt hooks, remote jobs) are not in the R11E trap table.
- Memory-server extras: `mm_lnkfr`, `sms_*` (`sms_achp_acsi`, `sms_cach`, `sms_dmod`, `sms_iopr`, `sms_lenq`, `sms_lldm`, `sms_lset`, `sms_mptr`, `sms_pset`, `sms_schp`, `sms_sevt`, `sms_wevt`), and `c_extop`.
- Screen and windows: `sd_*` (arc, extop, fount, gcur, iarc, ielipse, igcur, iline, ipoint, iscale, line, point, routine) and `ut_*` (con, cstr, err, link, mint, mtext, scr, unlnk, windowf). The virtual framebuffer is outside R11E.

Each unsupported name is listed with its reason in `docs/R11E-C68-XREF.csv`
(`qdos386_equivalent` empty, `notes` describing the gap).

## Method

1. `scripts/r11e-c68-xref.py` reads the C68 prototypes and writes the cross-reference.
2. The C89 coverage table (`docs/R11E-C89-COVERAGE.csv`, generated by
   `scripts/r11e-coverage.py`) takes its status from the exported symbols of the built
   libraries, and its `guest_tested` column from the R11E run list.
3. Each native wrapper is covered by a guest test in `sdk/examples/r11e/` (QDOSAPI, PS,
   CHILD1, CHILD2, CONWAIT, EXITX, EXITR, STREAM, REPEAT) where the kernel allows it.
