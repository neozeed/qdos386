# R11D blocked and limited C89 APIs

Every function listed here is either absent or fails explicitly. None is
provided as a success-returning stub. The authoritative per-symbol status is
`docs/R11D-C89-COVERAGE.csv` (generated by `scripts/r11d-coverage.py` from the
exported symbols of the built libraries).

## Kernel or filesystem blocked (status `blocked`)

| API | Current behaviour | Missing service | Future milestone |
|---|---|---|---|
| `remove`, `rename` | return -1 | writable FAT16 directory operations | FAT write milestone (FAT16 is read-only in R11D) |
| `tmpfile`, `tmpnam` | return NULL | writable file namespace | FAT write milestone |
| `freopen` | returns NULL; original stream is **not closed** (C89 requires it closed first) | none for the failure; closing is a deviation | R12 stdio cleanup |
| `fopen` write modes (`w`, `a`, `+`) | fail | writable FAT16 | FAT write milestone |
| `time` | returns (time_t)-1 | calendar clock: no RTC service in the trap ABI | R12-QDOS: RTC or host-time service |
| `mktime`, `gmtime`, `localtime`, `ctime` | fail (NULL or -1) | depend on `time` | R12-QDOS |
| `strftime` | returns 0 | depends on a calendar time base for real use | R12-QDOS |
| `clock` | returns (clock_t)-1 | a verified tick-to-CLOCKS_PER_SEC mapping. `_qd_ticks` exists in libqdos but its rate and wrap-around are not verified | R12-QDOS |
| `signal`, `raise` | SIG_ERR, -1 | asynchronous delivery; the kernel has no signal model | not planned; complete signals are out of scope |

## Working with documented limits (status `partial`)

| API | Limit |
|---|---|
| `getenv` | always NULL: there is no environment |
| `system` | `system(NULL)` returns 0 (no command processor exists); any command returns -1 |
| `setlocale`, `localeconv`, `mblen` | the C locale only; other locale names fail |
| `gets` | unbounded read from stdin, as C89 specifies; use `fgets` |
| `abort` | terminates the job with status 3 and does **not** flush stdio (C89 requires termination, not flushing) |
| `fgetpos`, `fsetpos` | positions as in `fseek`/`ftell`; read-only FAT16 files only |
| `perror`, `strerror` | messages for the C89 errno values in `errno.h`; values outside that set print "Unknown error" |

## Not provided

- Wide characters: `wchar_t` is not defined as a usable type; `mbstowcs`, `mbtowc`,
  `wcstombs`, `wctomb` are not exported and no `wchar.h` exists.
- POSIX, `fork`, `exec`, pipes, process groups: not provided.
- Paging, relocatable a.out, FAT16/FAT32 writes, VFAT long names: out of scope for R11D.
